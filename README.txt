راه‌اندازی (روی سرور خودتان، لینوکس):
1) pip install -r requirements.txt
2) توکن را فقط به‌صورت متغیر محیطی بدهید (داخل کد ننویسید):
   export BOT_TOKEN="توکن_ربات"
3) python bot.py
برای اجرای دائمی از systemd یا screen استفاده کنید.
TONCENTER_KEY اختیاری است (کلید رایگان از @tonapibot) و سرعت/پایداری بررسی تراکنش‌ها را بهتر می‌کند.
